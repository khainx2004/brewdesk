# Môi trường chạy — thiết lập và cạm bẫy

Cập nhật: 26/07/2026

## Chạy nhanh
```bash
sudo docker compose up -d                        # DB (Docker rootful, cần sudo)
set -a && . ./.env && set +a                     # PHẢI export env trước
cd source/backend && ./mvnw spring-boot:run      # cổng 8080
cd source/frontend && npm run dev                # cổng 5173
```
Đăng nhập: `admin` / `admin123` (bắt đổi mật khẩu lần đầu). Backend chạy ở terminal
**hoặc** IntelliJ, không phải cả hai.

## Cạm bẫy (đừng chẩn đoán lại)
- **`password authentication failed for user "brewdesk_user"`** → gần như luôn do
  quên export env, KHÔNG phải sai mật khẩu DB. `application.yml` cố ý không đặt mặc
  định cho `DB_PASSWORD`/`JWT_SECRET` (fail sớm thay vì lộ credential). Spring Boot
  **không** tự đọc `.env`.
- **Exit code không phản ánh app sống hay chết.** `mvnw spring-boot:run` in `BUILD
  SUCCESS` / IntelliJ in `exit code 0` kể cả khi app chết lúc boot. Phải đọc log.
- **Cần JDK `-devel`** (có `javac`): `sudo dnf install java-25-openjdk-devel`.
- **DB là Docker rootful** (không podman). User không thuộc nhóm `docker` → mọi lệnh
  `docker` cần `sudo` (thiếu → `permission denied ... docker.sock`).
- **Container `brewdesk_db` mặc định `restart=no`** → reboot xong DB không tự lên
  (triệu chứng: `Connection refused ... 5432`). Bật:
  `sudo docker update --restart unless-stopped brewdesk_db`.
- **Cổng bận** (`Port 8080 in use`, vite nhảy 5174) → tiến trình phiên trước chưa
  tắt: `ss -ltnp | grep -E ':(8080|5173)'` rồi `kill <pid>`. Vite ở 5174 vẫn chạy
  (proxy `/api` gắn dev server, không gắn số cổng).
- **`pkill -f "spring-boot:run"` tự giết chính nó** (khớp dòng lệnh script). Dùng
  `pkill -f "[s]pring-boot:run"` và **không** đặt lệnh khởi động lại cùng một dòng.
- **Jackson 3** (`tools.jackson.*`) — chi tiết ở `0.backend-phase.md` mục "Cạm bẫy
  tái diễn".
- **Sửa migration đã apply** làm hỏng Flyway checksum (đã dính một lần — phải xoá
  dòng trong `flyway_schema_history`). Luôn viết file V mới.
- **`spring-boot:run` không tự nạp lại `src/main/resources`** (migration mới) → phải
  restart tiến trình. (Có devtools thì `mvn compile` lại tự apply — xem backend doc.)

## IntelliJ (Flatpak, sandbox `filesystems=home;xdg-run/{docker,keyring,podman}`)
- **Không thấy JDK hệ thống** (`/usr/lib/jvm` ngoài sandbox). Sửa: Project Structure
  → SDKs → Download JDK (vào `~/.jdks`), hoặc **copy** (không symlink) JDK vào `~/.jdks`.
- **Không thấy `node`/`npm`** → chạy frontend bằng terminal Fedora thật, không dùng
  terminal tích hợp IDE.
- **Run config phải khai env thủ công** (Modify Run Configuration → Environment:
  `DB_PASSWORD`, `JWT_SECRET`), hoặc plugin **EnvFile** trỏ tới `.env` tuyệt đối.
  Triệu chứng thiếu: log in `Value: "${JWT_SECRET}"`.
- Project mở ở `source/backend/` nên không thấy `.env`/`doc/`/`design/` (ở gốc repo)
  → Add Content Root trỏ gốc repo.
